--------------------------------------------------------------------------------
HOW TO START THE DEMO
--------------------------------------------------------------------------------
1. Double-click "START_SETU.bat" in this folder.
2. The launcher will automatically verify the local environment and start
   the SETU Emergency Fusion Engine.
3. Your default web browser will automatically open to:
   http://127.0.0.1:8000
4. You will see the SETU Responder Console.

--------------------------------------------------------------------------------
HOW TO RUN THE FUSION PIPELINE DEMO
--------------------------------------------------------------------------------
1. In the top command header, click:
   "⚡ Process Intelligence Pipeline"
2. The engine will deterministically fuse 20 multi-channel reports into:
   - 13 Candidate Incidents across 5 Geographic Groupings (4 named zones + GPS/Outskirts)
   - 1 Physical Contradiction flagged for human responder resolution
3. Inspect incidents, review explainable evidence, and perform human verification.

--------------------------------------------------------------------------------
HOW TO STOP THE DEMO
--------------------------------------------------------------------------------
Return to the SETU launcher terminal window and press [ENTER] to cleanly
stop the engine.
